# AgriAlert Admin Frontend

Interface d'administration pour la plateforme de diagnostic agricole **AgriAlert**, développée avec **React** et **Vite**.

---

## 📋 Prérequis

Avant de lancer le projet, assurez-vous d'avoir installé sur votre machine :
* **Node.js** (Version 18 LTS ou supérieure recommandée - [Télécharger Node.js](https://nodejs.org/))
* **Git** ([Télécharger Git](https://git-scm.com/))

---

## 🚀 Installation

1. **Cloner le dépôt sur votre machine :**
   ```bash
   git clonehttps://github.com/Ayouba92/agrialert-admin-frontend.git
   cd agrialert-admin-frontend


Installer les dépendances du projet :(Note : Si vous rencontrez des conflits de versions avec React 19, utilisez l'option --legacy-peer-deps):npm install --legacy-peer-deps

Demarer le serveur:npm run dev
